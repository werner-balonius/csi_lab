# 1 m 连续空场漂移诊断（2026-08-28）

## 结论

正式距离实验继续暂停。保持监控接口和发射端五分钟不重置后，CSI 频谱仍明显变化：
node1 后 270 秒前后半差异为 `2.527%`，node3 为 `12.884%`。因此跨 trial
射频重新初始化不是主要根因；最可能的是 node3 路径附近的时变多径/物理变化，
但仍需通过接收机与位置交换实验排除 node3 自身的频率选择性射频状态跳变。

该试验是失败诊断，不得进入距离准确率、灵敏度或人体识别统计。

## 已排除与尚未排除

已排除：

1. 跨 trial 重新准备网卡：五分钟全程没有重建监控接口或发射进程。
2. 丢包/错配：匹配率超过98%，重复键约0.01%，时间戳单调。
3. 纯宽带功率变化：RSSI中位数全程不变，分析也已消除每根天线的宽带增益。
4. 单调温度漂移：node3 在高差异段后曾恢复到1.926%，变化不是单调的。

尚未区分：

1. node3 位置附近的人员、门、家具、线缆、支架或其他反射物变化。
2. node3 接收机自身可逆的频率选择性状态变化。
