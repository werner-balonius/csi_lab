# lag 容忍度：当前对齐已近最优，M0–M3 收益有限（2026-08-24）

## 结论

**扫描 lag ∈ [−1000, +1000] ms，最优 lag\* = −10 ms（约 1/3 个相机帧）。
两种独立特征（频谱、相位）收敛到同一结果。**

由此判定：**当前 CSI↔标签对齐已接近最优，
队友提出的 M0–M3 对齐方法对比收益上限有限，建议暂缓。**

---

## 一、为什么不能直接照原方案做

Zhuo Chen 在 V4 文档 §7 提议施加 0/±33/±66/±100/±200 ms 额外 lag，
观察性能下降。**该问法在本数据上没有统计功效。**

先算两条曲线再决定做不做：

### 1.1 oracle 灵敏度（功效上限）

即使预测器完美，施加 lag 造成的理论涨幅由**标签自身的时间自相关**决定，
与模型无关：

| lag | 标签自身 RMSE | 相对 0.53 m 残差的涨幅 |
|---|---|---|
| 33 ms | 0.122 m | **2.6%** |
| 66 ms | 0.145 m | **3.7%** |
| 100 ms | 0.173 m | 5.2% |
| 200 ms | 0.251 m | 10.7% |
| 500 ms | 0.509 m | 38.7% |
| 1000 ms | 0.923 m | 100.9% |

### 1.2 噪声底

三条留出 trial 的时间基线残差为 0.726 / 0.652 / 1.146 m，
**变异系数 31.7%**。

### 1.3 对照

| lag | 理论效应 | 噪声底 | 可测 |
|---|---|---|---|
| **33 ms** | 2.6% | 31.7% | ✗ |
| **66 ms** | 3.7% | 31.7% | ✗ |
| 200 ms | 10.7% | 31.7% | ✗ |
| 500 ms | 38.7% | 31.7% | ✓ |

**±33/±66 ms 的效应比噪声底小一个数量级。**

若照原方案做，必然得到平坦曲线；而平坦曲线有两种解释——
「模型不用精细时间信息」或「实验没有功效」——**两者无法区分**。

> 这正是 8-20 置换检验踩过的坑：得到阴性结果，
> 却不知道是真阴性还是没测出来。
> **教训已内化为规程：阴性结论必须先证明实验有功效。**

## 二、改进的问法

不问「性能掉多少」，改问 **「最优 lag 落在哪」**。

```
扫描 lag ∈ [−1000, +1000] ms，找 RMSE 曲线最小值位置 lag*

    lag* ≈ 0        -> 当前对齐已近最优，M0–M3 无收益
    lag* 显著偏 0    -> 存在系统性时间偏移，值得修正
```

**为什么更稳健**：极值位置不依赖绝对涨幅。
三条 trial 的残差水平差异很大（0.65 vs 1.15 m），
但只要各自曲线最低点都落在 0 附近，结论就成立。
**噪声影响曲线高度，不影响极值位置。**

### 关键设计：扫描范围必须足够宽

| 扫描范围 | 边缘/中心 | L1 判定 |
|---|---|---|
| ±200 ms | +9.2% | **不通过**（误判为无功效） |
| **±1000 ms** | **+81.0%** | **通过** |

只扫 ±200 ms 时看到的是一段平地，无法确认极值存在。
**扫到 ±1000 ms 才显出清晰的 V 形。**

## 三、结果

### 3.1 主扫描（归一化频谱 PCA-32）

| lag (ms) | pilot_01 | pilot_02 | pilot_03 | 平均 |
|---|---|---|---|---|
| −1000 | 0.905 | 0.931 | 0.941 | 0.926 |
| −670 | 0.754 | 0.788 | 0.781 | 0.774 |
| −340 | 0.626 | 0.590 | 0.606 | 0.607 |
| −175 | 0.611 | 0.580 | 0.576 | 0.589 |
| **−10** | **0.563** | **0.488** | **0.546** | **0.532** |
| +155 | 0.637 | 0.530 | 0.595 | 0.588 |
| +320 | 0.667 | 0.643 | 0.655 | 0.655 |
| +650 | 0.815 | 0.763 | 0.842 | 0.806 |
| +980 | 1.010 | 0.948 | 1.046 | 1.002 |

**曲线呈清晰 V 形，最低点在 lag ≈ 0。**

### 3.2 三层判据

| 层 | 检验 | 结果 | 判定 |
|---|---|---|---|
| **L1** | 曲线有明确极值 | 边缘/中心 = 0.964/0.532 = **+81.0%** | 通过 |
| **L2** | 最优 lag 一致性 | +23 / −10 / −10 ms | 一致 |
| **L3** | 极值显著偏 0 | 平均 lag\* = **−10 ms** | 接近 0 |

### 3.3 零对照（关键）

把 CSI 特征按样本打乱后重跑：

| | lag\* | 边缘涨幅 |
|---|---|---|
| 频谱特征 | +485 ms | **−3.9%** |
| 相位特征 | +980 ms | **+0.4%** |

**打乱后曲线平坦（|涨幅| < 4%），且 lag\* 位置随机。**

这排除了本设计最大的风险：极值来自标签自相关而非真实对齐。
主扫描的 81% 曲率确实来自 CSI 与标签的真实时间对应关系。

### 3.4 跨特征验证

| 特征 | 边缘/中心 | lag\* | 结论 |
|---|---|---|---|
| 归一化频谱 PCA-32 | +81.0% | **−10 ms** | 近最优 |
| 校准相位 PCA-32 | +65.4% | **−10 ms** | 近最优 |

**两种独立特征收敛到同一 lag\*，结论稳健。**

> 相位特征的 L2 判定为「不一致」（+122 / −10 / −76 ms），
> 但三条曲线的平均极值仍在 −10 ms，
> 且各 trial 极值散布均在 ±4 个相机帧内。
> 这反映相位特征的单 trial 噪声更大，不改变总体结论。

## 四、这个结果说明什么

### 4.1 对 M0–M3 的判断

lag\* = −10 ms，**小于 1/3 个相机帧**（30 fps 下一帧 33.3 ms）。

结合队友实测的相机配对误差中位数 7.9–8.7 ms，
两者量级一致——**当前 M1（epoch 最近帧）已经把对齐做到了帧量化极限**。

M2（线性插值）理论上能消除的正是这部分帧量化误差。
由 §1.1 的 oracle 曲线，33 ms 对应理论涨幅仅 2.6%，
**即 M2 相对 M1 的收益上限约为 2.6%**，
而 trial 间离散度是 31.7%。

**建议：暂缓 M0–M3，优先做空间分辨能力判据实验。**

### 4.2 一个更重要的旁证

这条曲线还独立印证了**标签是可信的**。

若深度标签有系统性错误或时间戳错位，
RMSE 曲线的最低点不会落在 lag = 0。
现在两种特征都指向 −10 ms，说明：

- `depth_to_label.py` 的躯干坐标提取正确
- 特征表的 `depth_frame_median` 映射正确
  （实测 帧号 = 30.000 × t + 162.51）
- CSI 与相机的时基对齐正确

**这是继「空场 2.7% vs 有人 34–37%」之后，
标签质量的第二个独立验证。**

### 4.3 边界

- 本结论基于 3 条 walk trial，样本有限
- 仅检验了 X 坐标
- lag\* 的分辨率受限于扫描步长 33 ms（1 个相机帧）
- **不能推广为「对齐永远不重要」**——
  若未来改用更高帧率相机或更快的运动，结论可能不同

## 六、方法学要点（可复用）

1. **阴性结论前先算功效上限。**
   本例中 oracle 曲线（标签自一致性）给出了与模型无关的理论上限，
   一次计算就排除了一个注定失败的实验设计。

2. **换问法能救回没功效的实验。**
   「性能掉多少」不可测，「极值在哪」可测——
   后者对噪声不敏感，因为噪声影响曲线高度而非极值位置。

3. **扫描范围要宽到能看见两侧上升。**
   同一数据，±200 ms 判「无功效」，±1000 ms 判「通过」。

4. **零对照必须打乱特征而非标签。**
   打乱标签会同时破坏时间结构，无法区分「对齐有效」与「标签自相关」。
