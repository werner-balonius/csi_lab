# 5 m 等边三角形座椅布局

- 布局 ID：`5m_equilateral_chair_20260811`
- 基础几何与 `layout_no_chair.md` 相同。
- 座椅座位中心：node2–node3 中点 `(-1.250, 2.165) m`。
- 座面离地：0.500 m。
- 椅子正面朝向 node3/相机，靠背朝向 node2。
- 座椅：青绿色织物无扶手办公椅，黑色五脚轮旋转底座。
- 采集前固定全部脚轮与旋转方向，左侧木门保持关闭。

该布局只用于 `empty_chair` 与 `sit_to_stand`。分析时必须用 trial 内空场归一化，
避免模型把静态座椅差异当作动作类别。
