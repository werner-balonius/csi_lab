# `arm_wave_05m_pilot_01` 质量评估

## 结论

**通过，可计入 `arm_wave` 类。** RGB 时间线确认参与者面向相机、双脚基本固定并连续抬臂/挥臂；前后空场完整，全身均位于视野内。

## 完整性

- node1/node3 目标包 6912/6910，匹配 6852；匹配率 99.13%/99.16%。
- 234 个数据子载波，无非单调包。
- OAK-D-W 记录 1502 帧深度，30 FPS，序号缺口 0；H.265 可解码。
- 画面约 0–9 秒为空场，约 10–25 秒为挥臂动作，随后离场并恢复空场。

## 动态倍率

使用主要动作窗约 9–25 秒并与 `empty_05m_pilot_02` 比较：

| 指标 | node1 | node3 |
|---|---:|---:|
| RSSI 标准差倍率 | 0.70× | **1.94×** |
| 100 ms CSI 变化倍率，天线 0 | 1.97× | **2.84×** |
| 100 ms CSI 变化倍率，天线 1 | 1.90× | 1.37× |

结果弱于全身穿越但仍明显可检测，符合“原地上肢动作的整体功率扰动小于走路”的预期。动作类别区分仍须在三次重复完成后用 CSI 子载波/时频特征验证，不能仅凭本条倍率下结论。
