# `walk_link2_05m_pilot_03` 质量评估

## 结论

**通过，可计入 `walk_link2` 类。** RGB-D 确认前后空场完整，人体在主要动作段清晰进入 Link2 区域；第三次试验再次呈现 node3 更强的 Link2 特异响应。

## 完整性

- node1/node3 目标包 6908/6929，匹配 6861；匹配率 99.32%/99.02%。
- 234 个数据子载波，无非单调包。
- OAK-D-W 记录 1501 帧深度，30 FPS，序号缺口 0；H.265 可解码。
- 画面约 0–8 秒为空场，约 9–25 秒有人体动作，末段重新回到空场。

## 动态倍率

使用主要动作窗约 9–25 秒并与 `empty_05m_pilot_02` 比较：

| 指标 | node1 | node3 |
|---|---:|---:|
| RSSI 标准差倍率 | 0.95× | **2.75×** |
| 100 ms CSI 变化倍率，天线 0 | 2.92× | **4.69×** |
| 100 ms CSI 变化倍率，天线 1 | 2.28× | **2.16×** |

CSI 倍率按每个 100 ms 窗的平均幅度做相邻窗差分，再与同一空场基线比较。RSSI 的 node1 对照接近 1，而 node3 连续三次均明显增强，是本条试验的主要通过依据。
