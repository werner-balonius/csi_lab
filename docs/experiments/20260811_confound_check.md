# 动作类可分性检验与一处混杂发现（2026-08-11 pilot）

本文做两件事：检验三类小动作**彼此之间**能否区分；同时报告一个
足以推翻前一份分析的混杂问题。

前一份：[`20260811_subcarrier_features.md`](20260811_subcarrier_features.md)

---

## 一、结论先行

**前一份分析（`20260811_subcarrier_features.md`）的核心结论不成立。**

它报告静止 vs 小动作在若干特征上 p = 0.0028–0.0084、留一交叉验证 85%。
但那批 trial 的**类别与采集时间几乎完全共线**，无法区分
「动作效应」与「时间漂移」。

动作类之间的可分性检验也未达显著。

## 二、混杂：类别与采集时间共线

按采集时刻排列全部有效 trial：

| 时段 | 类别 |
|---|---|
| 15:30 – 16:12 | `empty` ×3 |
| 15:44 – 16:25 | `walk_link2` ×5 |
| **16:32 – 17:03** | **`arm_wave` ×3、`leg_lift` ×3** |
| 17:15 | `empty_chair` ×1 |
| **17:21 – 17:29** | **`sit_to_stand` ×3** |

**所有静止类都在前，所有小动作类都在后。**

前一份报告的显著特征与采集时刻的相关系数：

| 特征 | 与采集时刻的 r |
|---|---:|
| `a1_freq_var` | **−0.758** |
| `a1_amp_std` | **−0.662** |
| `antratio_std` | −0.484 |
| `a1_chg_top10` | −0.278 |

在这种设计下，「静止 vs 动作」的差异与「早 vs 晚」的差异在统计上不可区分。
前一份的 p 值和交叉验证准确率因此不能作为动作效应的证据。

### 唯一的判据也不干净

`empty_chair_05m_pilot_01` 是静止类，却采于 17:15（落在动作类时段中间）。
若特征真反映动作，它应靠近静止侧；若只反映时间漂移，应靠近同期动作侧。

| 特征 | 早期静止 | `empty_chair` | 同期动作 | 判定 |
|---|---:|---:|---:|---|
| `a1_amp_std` | 0.97 | 0.72 | 0.65 | 偏动作 |
| `a1_freq_var` | 0.98 | 0.75 | 0.50 | 偏静止 |
| `a1_chg_mean` | 0.99 | 0.79 | 0.77 | 偏动作 |
| `a1_chg_top10` | 1.00 | 0.89 | 0.79 | 偏动作 |
| `antratio_std` | 0.89 | 0.89 | 0.74 | 偏静止 |

5 个特征中 3 个偏动作侧、2 个偏静止侧，且样本仅 1 条。**无法据此判定。**

这也让前一份提出的「动作时特征值反而更低」的假设失去依据 ——
数值随时间单调下降，同样能解释这个现象。

## 三、动作类之间的可分性

### `arm_wave` vs `leg_lift`（同为无座椅布局，无布局混杂）

3 vs 3，精确置换检验 C(6,3)=20 种分组，**最小可能 p = 2/20 = 0.10**。

| 特征 | `arm_wave` | `leg_lift` | 分离 | p |
|---|---:|---:|---|---:|
| `a0_amp_std` | 0.73 | 0.99 | 完全 | 0.10 |
| `antphase_chg` | 1.27 | 0.81 | 完全 | 0.10 |
| `antratio_std` | 0.61 | 0.74 | 完全 | 0.10 |

3 个特征完全分离看似可观，但需校正多重比较（共检验 11 个特征）：

在全部 20 种分组中，能达到「≥3 个特征完全分离」的有 **4 种**，
故校正后 **p = 0.20**。**未达显著。**

即使不考虑混杂，3 vs 3 的样本量也无法给出 p < 0.10 的证据 ——
这是检验方法的下限，不是数据的问题。

### `sit_to_stand` 不能纳入三类比较

它使用座椅布局，另两类无座椅。类别与布局共线，比较结果无法解释。

## 四、这批数据能支持什么

| 结论 | 是否成立 |
|---|---|
| 采集与同步管线可靠 | **成立**（匹配率 98.99–99.48%，深度零缺口） |
| `walk_link2` 有真实响应 | **成立**（trial 内自归一化 1.43–1.59×，三次一致） |
| 小动作可与静止区分 | **不成立**（与采集时间共线） |
| 小动作之间可区分 | **不成立**（校正后 p = 0.20） |
| 天线 1 优于天线 0 | **不成立**（同一混杂） |
| 动作时特征值更低有物理含义 | **不成立**（时间漂移同样能解释） |

`walk_link2` 之所以不受此问题影响，是因为它的判据是
**trial 内前后空场对比**，基线与信号来自同一次采集，不跨 trial。

## 五、下次采集必须修正的设计

1. **随机化或交错采集顺序**。不要按类别分块采集。
   例如 `empty → arm_wave → empty → leg_lift → empty → ...`。
2. **每类动作前后都插入同布局空场**，使每条动作 trial 都有紧邻的基线。
3. **布局与类别解耦**。若必须用座椅，则所有类别都在座椅布局下各采一遍。
4. **记录环境协变量**：温度、时间、开关门状态、其他人员位置。
5. **样本量**：3 vs 3 的置换检验下限就是 p = 0.10。
   若要 p < 0.05，每组至少需 4 条（C(8,4)=70，最小 p = 2/70 ≈ 0.03）；
   要有余量则建议每类 ≥ 8 条。

## 六、方法学教训

trial 内基线（`20260811_baseline_review.md` 的做法）能消除**跨 trial**
的状态差异，但**不能消除跨 trial 的系统性趋势**——
因为比值本身仍随时间漂移。

判断某个特征是否反映目标效应，除了看组间差异，还须检查
它与采集顺序、时间、环境变量的相关性。本次若未做这一步，
就会得出一个 p < 0.01 但实际站不住的结论。
