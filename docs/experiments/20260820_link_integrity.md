# 链路通畅性验证与 AGC 补偿效应（2026-08-20）

本文报告一组受控遮挡实验（8 条 trial）及基于其结论的 8-06 数据重新分析。
四个产出：

1. **验证测量链路通畅**——系统对物理遮挡有明确、可重复、可逆的响应。
2. **发现 AX210 的 AGC 会掩盖遮挡**——实测补偿 +13.88 dB。
3. **金属板遮挡链路中点**——RSSI −4.57 dB，频谱形状 27.27%，信噪比 127×。
4. **8-06「CSI 对人体无响应」的结论不成立**——同一批数据换用正确特征后，
   `block_test` 与三条 `walk_link1` 全部呈现 2.8–4.1× 响应。

第 2、4 点推翻了一个持续两周的判断，使 8-06/8-07 共 14.4 GB 数据恢复可用。

---

## 一、结论先行

**测量链路通畅。** 屏蔽 node1 天线使 RSSI 下降 **14.00 dB**（接收功率降至 4%），
移除后**精确回到 −33.0 dBm**。5 m 外的 node3 全程不动（−0.04 dB）。

**但 `|H|` 的绝对幅度对此几乎无反应（−0.13 dB）。**

| 量 | 变化 | 含义 |
|---|---|---|
| RSSI | **−14.00 dB** | 真实功率，掉了 96% |
| `\|H\|` 全频带均值 | **−0.13 dB** | AGC 之后，几乎不变 |
| **推算 AGC 补偿** | **+13.88 dB** | 固件自动补回 |

AX210 的接收增益由固件 AGC 控制，不可关闭。`|H|` 是 AGC **之后**的量，
因此遮挡造成的功率损失被自动补偿掉了。

**这就是 8-06 的谜团。** 当时一人静站链路中点 45 秒，`|H|` 仅变 −2.6%，
据此判定「接收信号对人体遮挡几乎不响应」。真相是：人确实挡住了信号，
AGC 把它补了回来。

## 二、布局与协议

推进至短链路，node3 作远场空间对照：

| | 距离 | 角色 |
|---|---|---|
| node2 (Tx) → **node1** | **1 m** | 测试链路，接收端被屏蔽 |
| node2 (Tx) → node3 | 5 m | 空间对照，不做任何操作 |

PHY：2412 MHz、`TX_CBW_20_HESU`、20 MHz、234 数据子载波（242 减 8 导频）。
每条 trial 15 s、约 2950 包、无相机。

**A-B-A 设计**，全程同一次开机内完成，未重启、未移动节点：

| trial | 条件 | 目录 |
|---|---|---|
| base1 | 无屏蔽 | `20260820_154143_1t2r_mA1_base` |
| base2 | 无屏蔽 | `20260820_154305_1t2r_mA2_base` |
| foil1 | node1 天线包铝箔 | `20260820_154707_1t2r_mB1_foil_ant` |
| foil2 | node1 天线包铝箔 | `20260820_155030_1t2r_mB2_foil_ant` |
| recov | 移除铝箔 | `20260820_161121_1t2r_mA3_base_recover` |
| plate1 | 金属板挡链路中点 | `20260820_162326_1t2r_mC1_plate_mid` |
| plate2 | 金属板挡链路中点 | `20260820_162502_1t2r_mC2_plate_mid` |
| final | 移除金属板 | `20260820_162718_1t2r_mA4_base_final` |

金属板约 20–35 cm，两块拼接，立于中点（各 50 cm），板面垂直于链路，
板中心对准天线高度，人不接触、采集时离开链路区。

采集质量：匹配率 98.96–99.60%，均为 234 子载波，无非单调时戳。

**只包天线、不包机身。** 包裹整机会同时改变天线阻抗、机身电磁环境与接地状态，
无法区分「遮挡」与「天线失谐」。（另：包整机存在散热与短路风险。）

## 三、结果

### 3.1 RSSI：完整的 A-B-A

```
node1:  −33.0 → −33.0 → −47.0 → −47.0 → −33.0
node3:  −38.9 → −39.0 → −39.0 → −39.0 → −38.5
```

node1 两个屏蔽态**读数完全一致**（均为 −47.00），恢复态**精确回到 −33.0**。
node3 全程波动 ≤ 0.5 dB。

### 3.2 频谱形状：信噪比 96×

归一化频谱（除以各自均值后逐子载波比较）的 L2 距离：

| | node1（被屏蔽） | node3（5 m 对照） |
|---|---|---|
| 零基线（base1 vs base2） | **0.22%** | 0.51% |
| 屏蔽效应（base2 vs foil） | **20.76% / 22.11%** | 6.25% / 3.81% |
| 屏蔽态内部重复（foil1 vs foil2） | 2.41% | 3.18% |
| **信噪比** | **96.6×** | 12.4× |

零基线 0.22% 说明场地极稳定；屏蔽效应 21% 是其 **96 倍**。

node1 距离矩阵（%）：

```
          base1   base2   foil1   foil2   recov
base1      0.00    0.22   20.63   21.98   12.10
base2      0.22    0.00   20.76   22.11   11.97
foil1     20.63   20.76    0.00    2.41   26.49
foil2     21.98   22.11    2.41    0.00   27.02
recov     12.10   11.97   26.49   27.02    0.00
```

两个条件各自内聚（0.22 / 2.41），条件间分离（21），结构清晰。

### 3.3 AGC 补偿

```
天线0: 151.0 → 149.9  (−0.07 dB)
天线1: 142.4 → 139.3  (−0.19 dB)
```

两根天线都几乎不变，与 RSSI 的 −14 dB 形成尖锐对比。

AGC 是**宽带增益**，只整体缩放不改变频谱形状——这正是归一化频谱仍能测出
20.76% 变化的原因，也是它可作为可靠特征的依据。

## 三之二、金属板遮挡链路中点

铝箔实验屏蔽的是**接收天线**，与人体**遮挡链路**机制不同。补做后者。

### RSSI 全序列

```
node1:  −33.0  −33.0 │ −47.0  −47.0 │ −33.0 │ −37.6  −37.3 │ −32.0
        base1  base2 │ foil1  foil2 │ recov │ plate1 plate2 │ final
node3:  −38.9  −39.0 │ −39.0  −39.0 │ −38.5 │ −38.8  −38.8 │ −38.5
```

### 两种遮挡对比（node1）

| 条件 | RSSI | `\|H\|` 均值 | 归一化频谱 L2 |
|---|---|---|---|
| 铝箔包天线 | **−14.00 dB** | −1.44% | 20.76% |
| **金属板挡中点** | **−4.57 dB** | −3.40% | **27.27%** |
| 零基线 | — | — | 0.22% |

金属板重复性：27.27% / 26.86%，板内重复 2.17%。**信噪比 127×。**

**闭环恢复率 88%**（板前 vs 板后基线差 3.34%），显著优于铝箔实验的 44%
——因为全程未触碰天线，印证 §5.1 的判断。

### 两点解读

**1. RSSI 只掉 4.57 dB，符合预期。** 遮挡阻断直射径，但多径可绕行，
不会掉到零。**残余值本身量化了场地的多径底噪。**

**2. 频谱形状变化（27.27%）反而大于铝箔（20.76%）。**
铝箔是宽带均匀衰减，主要改变功率；遮挡直射径改变的是**多径结构**，
频率选择性更强。这进一步说明频谱形状是比功率更敏感的遮挡特征。

node3（5 m 外）RSSI 仅 −0.25 dB，但频谱有 11.13%/11.50% 变化——
金属板作为新散射体改变了房间整体多径。空间特异性仍成立
（node1 是其 2.4 倍），但说明**场地对任何物体的引入都敏感**，
人体实验中需严格控制场地内其他物体。

## 三之三、8-06 数据重新分析：原结论不成立

用本文确立的方法重算 8-06 全部 trial（本地备份
`~/csi_archive/20260806_07_early/`）。

### 指标：频谱形状时序变化能量

不依赖切点、不依赖协议标注：将 trial 切为 1 s 窗，各窗归一化频谱与全程均值的
L2 偏差的平均。

| trial | node1 | vs 空场 | 8-06 当时判定 |
|---|---|---|---|
| `empty_current_01` | 3.47% | — | 合格 |
| `empty_current_02` | 1.89% | — | 合格 |
| **`block_test`（人静站 45 s）** | **11.06%** | **4.1×** | 「无响应」❌ |
| **`walk_link1_05m_01`** | **8.70%** | **3.2×** | 「不合格」❌ |
| **`walk_link1_05m_02`** | **8.84%** | **3.3×** | 「不合格」❌ |
| **`walk_link1_05m_03`** | **7.49%** | **2.8×** | 「不合格」❌ |

（空场均值 2.68%）

**三条 `walk_link1` 全部有 2.8–3.3× 响应。** 当时反复重采三轮、判定不合格、
归因于「接收信号对人体不响应」——**均为分析方法造成的误判**。

### 三条独立证据

**① 效应量对照。** 同一最优切点扫描程序：

| | 最大效应 | 切点 |
|---|---|---|
| `block_test` | **20.65%** | 25 s |
| `empty_01` | 3.86% | 13 s |
| `empty_02` | 3.86% | 6 s |

空场上同样的程序最多只能挖出 3.86% 的假象，`block_test` 为其 **5.3 倍**。

**② 无监督变点检测。** 不使用任何先验，自动收敛到 **24.4 s**，
top5 候选全部落在 24.2–25.2 s。与 45 s 静站协议一致，排除确认偏差。

**③ 与 8-20 受控实验量级一致。** `block_test` 前后段 19.84%，
铝箔 20.76%，金属板 27.27%——同一量级。

### 方法学警告：置换检验在此类数据上失效

本次分析中先后尝试并**否决**了两种检验：

| 方法 | 空场对照结果 | 判定 |
|---|---|---|
| 随机置换（n=5000） | 空场也 p = 0.0000 | ❌ 破坏时间自相关 |
| 循环块移位（n=44） | `empty_02` 反而 p = 0.0000 | ❌ 对单调漂移失效 |
| **同程序跑空场作零分布** | 空场 3.86%，有人 20.65% | ✅ 采用 |

**CSI 时序高度自相关，标准置换检验会产生虚假显著性。**
正确做法是用空场数据跑完全相同的分析程序，以其结果作为零分布。

> `20260811_confound_check.md` 等早期分析若使用了置换检验，需按此复核。

### 两个指标测的不是同一件事

| 指标 | 测什么 | 适用场景 |
|---|---|---|
| **trial 间频谱 L2** | 两个条件的稳态差异 | 条件在 trial 内**不变**（8-20 金属板/铝箔） |
| **trial 内变化能量** | 单条 trial 内部的时序起伏 | 条件在 trial 内**改变**（8-06 人中途进入） |

用错会得到误导性结论。例如 8-20 金属板的 trial 内变化能量仅 1.41%
（空场 2.1 倍），看似很弱——因为板子全程静止，trial 内部本就稳定；
其效应体现在 **trial 之间的 27.27%**。反之 8-06 的人在中途走入链路，
**trial 内**变化能量 11.06% 才是恰当指标。

**选择原则：看条件在 trial 内是否发生变化。**

## 五、两处遗留问题

### 5.1 恢复率仅 44%

RSSI 完美恢复（−33.0），但频谱形状残留 11.97% 偏差（零基线 0.22%）。

最可能的原因是**包裹/移除铝箔时触碰了天线**。RSSI 是宽带功率，对毫米级位移
不敏感；频谱形状对相位极敏感。

> **实验纪律：任何触碰天线的操作都会改变基线。人体实验中不得触碰设备，
> 且基线必须就近采集（trial 内前后空场）。**

### 5.2 node1 RSSI 存在截顶

1 m 距离下 node1 RSSI 长期停在单一取值（本次 −33.00，另一次开机为 −35.00，
标准差 0.00–0.06）。这是报告上限，非物理值。

**推论：在未屏蔽状态下，RSSI 对 node1 的弱遮挡不敏感**——除非跌破截顶阈值。
本实验能测到 −14 dB 是因为屏蔽足够强。

node3（5 m，−38.9 dBm）未截顶。

## 六、剩余未回答的问题

**已回答**：金属板遮挡链路中点见 §3-2（RSSI −4.57 dB，频谱 27.27%）；
人体尺度响应见 §3-3（`block_test` 11.06%，空场 4.1 倍）。

**仍未回答**：

**1. 响应能否编码位置。** 目前只证明「有物体 / 无物体」可分。
姿态估计需要的是「物体在哪、什么构型」。8-14 的双链路幅度选择性
已证不可重复（0.44 vs 1.16），该方向需改用相位或多普勒。

**2. 标签生成从未验证。** 尚未从 OAK-D 深度图提取过任何人体坐标。
这是项目最大的未验证环节。

**3. 金属板 ≠ 人体。** 金属是全反射体，人体含水组织部分吸收、部分透射，
RCS 显著不同。§3-3 的 8-06 数据（真人）响应 11.06%，
低于金属板的 27.27%，量级差异需注意。

### 布局参数备忘

- 1 m 链路中点第一菲涅尔区直径 **0.35 m**（5 m 时为 0.79 m）——
  这可能是 8-06 响应偏弱的另一个原因：**人体躯干宽 0.4–0.5 m，
  在 5 m 链路上挡不满第一菲涅尔区。**
- 1 m 时直射径比地面反射强 **7.0 dB**；5 m 时仅强 **0.65 dB**。
  短链路的直射径占比显著更高，是遮挡实验更有利的配置。
