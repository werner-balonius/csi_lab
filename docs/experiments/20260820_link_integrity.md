# 链路通畅性验证与 AGC 补偿效应（2026-08-20）

本文报告一次受控屏蔽实验。它有两个产出：

1. **验证测量链路通畅**——系统对物理遮挡有明确、可重复、可逆的响应。
2. **发现 AX210 的 AGC 会掩盖遮挡**——这解释了 8-06「CSI 对人体无响应」
   的错误结论，并要求修改此后全部分析的特征选择。

第 2 点推翻了一个持续两周的判断，影响面大于第 1 点。

---

## 一、结论先行

**测量链路通畅。** 屏蔽 node1 天线使 RSSI 下降 **14.00 dB**（接收功率降至 4%），
移除后**精确回到 −33.0 dBm**。5 m 外的 node3 全程不动（−0.04 dB）。

**但 `|H|` 的绝对幅度对此几乎无反应（−0.13 dB）。**

| 量 | 变化 | 含义 |
|---|---|---|
| RSSI | **−14.00 dB** | 真实功率，掉了 96% |
| `\|H\|` 全频带均值 | **−0.13 dB** | AGC 之后，几乎不变 |
| **推算 AGC 补偿** | **+13.88 dB** | 固件自动补回 |

AX210 的接收增益由固件 AGC 控制，不可关闭。`|H|` 是 AGC **之后**的量，
因此遮挡造成的功率损失被自动补偿掉了。

**这就是 8-06 的谜团。** 当时一人静站链路中点 45 秒，`|H|` 仅变 −2.6%，
据此判定「接收信号对人体遮挡几乎不响应」。真相是：人确实挡住了信号，
AGC 把它补了回来。

---

## 二、布局与协议

推进至短链路，node3 作远场空间对照：

| | 距离 | 角色 |
|---|---|---|
| node2 (Tx) → **node1** | **1 m** | 测试链路，接收端被屏蔽 |
| node2 (Tx) → node3 | 5 m | 空间对照，不做任何操作 |

PHY：2412 MHz、`TX_CBW_20_HESU`、20 MHz、234 数据子载波（242 减 8 导频）。
每条 trial 15 s、约 2950 包、无相机。

**A-B-A 设计**，全程同一次开机内完成，未重启、未移动节点：

| trial | 条件 | 目录 |
|---|---|---|
| base1 | 无屏蔽 | `20260820_154143_1t2r_mA1_base` |
| base2 | 无屏蔽 | `20260820_154305_1t2r_mA2_base` |
| foil1 | node1 天线包铝箔 | `20260820_154707_1t2r_mB1_foil_ant` |
| foil2 | node1 天线包铝箔 | `20260820_155030_1t2r_mB2_foil_ant` |
| recov | 移除铝箔 | `20260820_161121_1t2r_mA3_base_recover` |

采集质量：匹配率 98.96–99.60%，均为 234 子载波，无非单调时戳。

**只包天线、不包机身。** 包裹整机会同时改变天线阻抗、机身电磁环境与接地状态，
无法区分「遮挡」与「天线失谐」。（另：包整机存在散热与短路风险。）

## 三、结果

### 3.1 RSSI：完整的 A-B-A

```
node1:  −33.0 → −33.0 → −47.0 → −47.0 → −33.0
node3:  −38.9 → −39.0 → −39.0 → −39.0 → −38.5
```

node1 两个屏蔽态**读数完全一致**（均为 −47.00），恢复态**精确回到 −33.0**。
node3 全程波动 ≤ 0.5 dB。

### 3.2 频谱形状：信噪比 96×

归一化频谱（除以各自均值后逐子载波比较）的 L2 距离：

| | node1（被屏蔽） | node3（5 m 对照） |
|---|---|---|
| 零基线（base1 vs base2） | **0.22%** | 0.51% |
| 屏蔽效应（base2 vs foil） | **20.76% / 22.11%** | 6.25% / 3.81% |
| 屏蔽态内部重复（foil1 vs foil2） | 2.41% | 3.18% |
| **信噪比** | **96.6×** | 12.4× |

零基线 0.22% 说明场地极稳定；屏蔽效应 21% 是其 **96 倍**。

node1 距离矩阵（%）：

```
          base1   base2   foil1   foil2   recov
base1      0.00    0.22   20.63   21.98   12.10
base2      0.22    0.00   20.76   22.11   11.97
foil1     20.63   20.76    0.00    2.41   26.49
foil2     21.98   22.11    2.41    0.00   27.02
recov     12.10   11.97   26.49   27.02    0.00
```

两个条件各自内聚（0.22 / 2.41），条件间分离（21），结构清晰。

### 3.3 AGC 补偿

```
天线0: 151.0 → 149.9  (−0.07 dB)
天线1: 142.4 → 139.3  (−0.19 dB)
```

两根天线都几乎不变，与 RSSI 的 −14 dB 形成尖锐对比。

AGC 是**宽带增益**，只整体缩放不改变频谱形状——这正是归一化频谱仍能测出
20.76% 变化的原因，也是它可作为可靠特征的依据。

## 四、对后续工作的约束

**1. `|H|` 的绝对幅度不能作为遮挡/存在性特征。** 它被 AGC 归一化了。
8-06 与部分早期分析使用了该特征，其阴性结论需重新审视。

**2. RSSI 必须记录并进入分析。** 它保留真实功率信息，是 AGC 补偿的唯一旁证。
注意 RSSI 在强信号下会截顶（见 §5），需配合使用。

**3. 归一化频谱形状是首选特征。** 对 AGC 免疫，本实验信噪比 96×。

**4. 全频带均值会抹掉信号。** 本实验中全频带 `|H|` 均值仅 −1.44%，
而逐子载波频谱形状变化 20.76%——差一个数量级。
这与 `20260811_baseline_review.md` 的结论一致，此处再获独立验证。

## 五、两处遗留问题

### 5.1 恢复率仅 44%

RSSI 完美恢复（−33.0），但频谱形状残留 11.97% 偏差（零基线 0.22%）。

最可能的原因是**包裹/移除铝箔时触碰了天线**。RSSI 是宽带功率，对毫米级位移
不敏感；频谱形状对相位极敏感。

> **实验纪律：任何触碰天线的操作都会改变基线。人体实验中不得触碰设备，
> 且基线必须就近采集（trial 内前后空场）。**

### 5.2 node1 RSSI 存在截顶

1 m 距离下 node1 RSSI 长期停在单一取值（本次 −33.00，另一次开机为 −35.00，
标准差 0.00–0.06）。这是报告上限，非物理值。

**推论：在未屏蔽状态下，RSSI 对 node1 的弱遮挡不敏感**——除非跌破截顶阈值。
本实验能测到 −14 dB 是因为屏蔽足够强。

node3（5 m，−38.9 dBm）未截顶。

## 六、本实验未回答的问题

**屏蔽接收天线 ≠ 遮挡链路。** 前者直接衰减到达接收机的全部能量；
后者阻断直射径，多径仍可绕行。

因此 **−14 dB 不能外推为「人挡在链路中间会掉 14 dB」**。

本实验证明的是**测量链路健康、系统对物理屏蔽有响应**。
「人体尺度的遮挡能产生多大响应」仍需金属板挡链路中点来回答。

规划该实验时的两个参数：

- 1 m 链路中点第一菲涅尔区直径 **0.35 m**（5 m 时为 0.79 m）——
  这可能是 8-06 响应微弱的另一个原因：**人体躯干宽 0.4–0.5 m，
  在 5 m 链路上挡不满第一菲涅尔区。**
- 1 m 时直射径比地面反射强 **7.0 dB**；5 m 时仅强 **0.65 dB**。
  短链路的直射径占比显著更高，是遮挡实验更有利的配置。

## 七、复现

```bash
cd ~/csi_lab
./csi_lab.sh mA1_base 15        # 无屏蔽
./csi_lab.sh mA2_base 15        # 无屏蔽（建立零基线）
# —— 包裹 node1 天线，人离开链路区 ——
./csi_lab.sh mB1_foil_ant 15
./csi_lab.sh mB2_foil_ant 15
# —— 移除铝箔 ——
./csi_lab.sh mA3_base_recover 15
```

分析：归一化频谱 L2 距离 + RSSI 均值，见 §3。

**前提**：全程同一次开机，不重启、不移动节点。跨重启数据不可直接比较——
实测 node3 跨重启频谱变化 12.77%，远超其零基线 2.83%（固件冷启动重新
RF 校准所致，同次开机内天线比稳定在 0.90，重启后变为 1.05）。
