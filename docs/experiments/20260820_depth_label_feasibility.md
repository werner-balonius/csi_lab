# 深度标签可行性验证（2026-08-20）

**项目此前从未从 OAK-D 深度图提取过任何人体坐标。** 没有标签就没有监督学习，
这是 Person-in-WiFi-**3D** 最大的未验证环节（文档 §16 亦承认「设备坐标不能
代替真值」）。

本文用 8-11 已有数据验证该环节，**零采集成本**。

**结论：可行。** 能稳定输出躯干 (X, Y, Z) 轨迹，空场对照干净，跨 trial 可重复。

---

## 一、数据与格式

`~/csi_archive/20260811_pilot/node3/*_cam/`，每条 trial 含：

| 文件 | 内容 |
|---|---|
| `*_depth.bin` | 640×360 uint16 小端裸深度，约 692 MB / 50 s |
| `*_cam.json` | 内参、逐帧时戳、时钟偏移 |
| `*_color.h265` | 含人像，不进 Git |

关键元数据：

```
depth:  640x360, uint16, little, 1502 帧, 30.0 fps, sequence_gaps=0
calib:  fx=fy=381.4918, cx=317.617, cy=186.962
        depth_unit=millimeter, baseline=7.5cm, aligned_to=CAM_A
```

**内参齐全**，可直接针孔反投影到真实三维坐标，无需额外标定。
深度有效像素 99.9%+，值域 2–14 m，无缺帧。

## 二、方法

[`scripts/depth_to_label.py`](../../scripts/depth_to_label.py)，仅依赖 numpy + scipy。
**不需要 PicoScenes toolbox 或 depthai**，可在 Mac 侧离线跑。

1. **背景建模**：全序列时间中位数。人只在少数帧占少数像素，中位数对其鲁棒。
2. **前景分割**：比背景近 300 mm 以上，且深度在 0.5–8 m。
3. **最大连通域**：`scipy.ndimage.label`，排除噪声与多目标。
4. **躯干提取**：取连通域纵向 25%–70% 区段，排除头顶与足部。
5. **反投影**：`X = (u−cx)·Z/fx`，`Y = (v−cy)·Z/fy`，输出米制。

输出 `torso_track.csv`：`frame, timestamp_ns, blob_px, X_m, Y_m, Z_m, blob_ratio`。

时戳直接取自 `depth.timestamp_ns_monotonic`，**与 CSI 对齐所需的时基一致**。

## 三、结果

### 3.1 人体判定阈值

原始前景检出率**无法区分**空场与有人（均 83–87%），因为背景残差也会被检出。
加连通域尺寸门限 `blob >= 10000 px` 后完全分离：

| trial | 人体帧占比 | Z 中位 | 判定 |
|---|---|---|---|
| **`empty_05m_pilot_02`（对照）** | **2.7%** | **5.73 m** | 无人 ✅ |
| `walk_link2_pilot_01` | **34.9%** | 2.35 m | 有人 ✅ |
| `walk_link2_pilot_02` | **33.9%** | 2.34 m | 有人 ✅ |
| `arm_wave_pilot_01` | **37.2%** | 2.48 m | 有人 ✅ |

- **空场 2.7% vs 有人 34–37%，约 12 倍差异。**
- Z 完全分离：空场残差在 5.7 m（背景墙），人体在 2.3–2.5 m。
- 两条独立 `walk` trial 占比 34.9%/33.9%、Z 相差 0.01 m——**方法可重复**。

空场那 2.7%（8 帧）的速度中位为 **5.43 m/s**，物理上不可能，
确认为噪声而非漏检的人。

### 3.2 主轨迹

`walk_link2_pilot_01` 检出一段 **16.2 s、98 点的连续轨迹**（帧 425–910）：

## 四、结论

**标签路线可行。** 具体地：

1. 能输出米制三维躯干坐标，时基与 CSI 对齐一致
2. 空场对照干净（12 倍分离）
3. 跨 trial 可重复
4. 轨迹符合运动学与实验协议
5. 纯离线，Mac 侧即可批量处理

**8-11 的 19 条带相机 trial 均可生成标签。**

---

## 五、四点局限

**1. 检出率仅 35%，不是漏检。**
50 s trial 中人只在约 16 s 内位于相机视野。其余时段人在场地边缘或视野外。
若需更高标注密度，采集协议应保证人全程在视野内。

**2. 7.8% 的速度跳变需要平滑。**
主要来自连通域瞬时分裂（如手臂与躯干断开）。用于训练前应做卡尔曼或中值滤波。
本脚本**不做平滑**，保留原始检出以便诊断。

**3. 坐标系是相机坐标系，不是场地坐标系。**
X 向右、Y 向下、Z 向前，原点在相机光心。要与节点坐标
（`layout_id=5m_equilateral_20260811`）关联，**仍需相机外参标定**——尚未开始。

**4. 只有躯干中心，不是 3D 骨骼。**
若课题目标是完整姿态估计，需引入姿态估计模型（如在 RGB 上跑
MediaPipe / OpenPose 再与深度对齐）。**当前输出只支持「人体位置」级别的监督。**

## 六、复现

```bash
cd ~/csi_lab
B=~/csi_archive/20260811_pilot/node3

# 有人
python3 scripts/depth_to_label.py $B/20260811_161724_walk_link2_05m_pilot_01_cam --stride 5
# 空场对照
python3 scripts/depth_to_label.py $B/20260811_160837_empty_05m_pilot_02_cam --stride 5
```

`--stride 5` 为 6 fps 抽样（约 1 分钟/trial）；`--stride 1` 得到全 30 fps。
