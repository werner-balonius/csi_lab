## 2. 三个阶段

| 阶段 | 做法 | 结果 |
|---|---|---|
| 8-06 | 穿越链路走动 | **失败**。人静站 link1 中点 45 s，node1 幅度仅降 2.6% |
| 8-07 | 重新布局 | **Link2 通过，Link1 仍失败**。静站 +3.06%/+2.92%，走动 RSSI 2.10×，node1 对照 0.82× |
| 8-11 | 转向原地动作 | 15 条有效样本，5 类各 3 条 |

8-06 失败有两个独立原因，都已确认：

1. **物理布局**。同样设备，新布局 Link2 得 +3.06%，旧布局仅 +0.22%，差一个数量级。
2. **分析方法错误**。当时用全频带幅度均值（`np.abs(csi).mean(axis=1)`）判断，
   而多径造成的频率选择性衰落在不同子载波上方向相反，跨子载波平均会相互抵消。
   正确做法是逐子载波计算变化能量。这个纠正来自队友，是对的。

阶段 2→3 的转向合理：Link1 的几何摆不出响应，与其死磕穿越链路，
不如换成对布局不那么敏感的原地动作。

## 3. 基线复核（本文核心）

### 3.1 问题

pilot README 的结果表用**外部空场**作基线（`empty_05m_pilot_02` 或
`empty_chair_05m_pilot_01`）。外部基线会把两次采集之间的状态差异计入"动作响应"。

同一份 README 的「分析限制」第 1 条已明确要求用 trial 内前后空场归一化 ——
但表格本身没有这么做。

### 3.2 两种基线的结果

指标 `node3_change_ant0`（100 ms 窗内逐子载波幅度变化能量）：

| 动作 | 外部空场基线 | **trial 内自归一化** |
|---|---|---|
| `walk_link2` | 3.98–5.50× | **1.43–1.59×** |
| `arm_wave` | 2.45–2.90× | **0.61–0.95×** |
| `leg_lift` | 2.53–2.77× | **0.71–0.93×** |
| `sit_to_stand` | 1.23–1.42× | **0.66–0.79×** |

### 3.3 差异来源

以 `arm_wave_05m_pilot_01` 为例：

```
动作段                     10.90
同一 trial 的前后空场段     11.46   ->  0.95x
外部空场 empty_05m_pilot_02  3.76   ->  2.90x
```

外部空场的基线值 3.76，而**同一次实验里人静止时是 11.46**，相差 3 倍。
表中的 2.90× 主要反映采集间的状态差异，不是手臂挥动本身。

各 trial 的两种基线倍数差为 1.6–4.2 倍，说明这不是个别现象。

### 3.4 结论

**目前站得住的只有一条：`walk_link2` 有真实响应。**
三次重复一致，trial 内自归一化后仍达 1.43–1.59×。

`arm_wave` / `leg_lift` / `sit_to_stand` 在 trial 内基线下均 ≤1，
即动作段的信号变化不强于同一次实验的静止段。**目前没有证据支持这三类可检测。**

这不代表小动作一定不可检测，可能是：

* 100 ms 窗 + 全子载波平均的特征对小幅动作不敏感；
* 动作段标注（`action_candidate_hint`）与实际动作时刻有偏差；
* 小动作的信号确实低于当前系统噪声水平。

需要更细的特征（子载波级、相位、时频）和更准的动作标注才能判定。

## 4. 一个需要撤回的说法

先前口头提出过"两根接收天线响应方向相反"（ant0 升、ant1 降）。
**这个说法不成立，来源是外部基线造成的假象。**

trial 内自归一化后，12 条动作 trial 的 ant0/ant1 **全部同向**：

| trial | ant0 | ant1 |
|---|---:|---:|
| `walk_link2_*` | 1.43–1.59 | 1.36–1.50 |
| `arm_wave_*` | 0.61–0.95 | 0.51–0.84 |
| `leg_lift_*` | 0.71–0.93 | 0.72–0.88 |
| `sit_to_stand_*` | 0.66–0.79 | 0.73–0.77 |

无一例方向相反。双天线工作正常。

## 6. 建议的下一步

### 不需要再采集

1. **统一用 trial 内基线重算全部结果**，并更新 pilot README 的表格。
   这决定后续所有结论的可信度。
2. 尝试更细的特征：子载波级差分、相位、短时频谱，看小动作能否浮现。
3. 核对动作段标注与 RGB 时间线的对应关系。

### 需要少量采集

4. 补 `empty_chair` 至 3 条。
5. 若要论证小动作，需先确定有效特征再设计采集，而非直接扩大样本量。

### 关于 5/10/15 m 三档实验

原计划 27 组**不宜按原样执行**：

* Link1 至今无响应，`walk_link1` 采了也是无效样本；
* 小动作在 trial 内基线下尚未证明有效；
* 每档需重新布局，而布局本身是最大变量（+3.06% vs +0.22%）。

务实做法：**先在 5 m 把方法学做扎实**（基线归一化、特征选择、可重复性验证），
再决定是否扩展到多档。
