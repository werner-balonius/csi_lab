## 2. 物理布置

```
node2(Tx) ●━━━━━━━━━━━━━━━━━━━━━━━━━━━● node1(Rx1)
          0m   A(0.75)  B(1.5)  C(2.25)  3m
                 ●        ●        ●

                        ● node3(Rx2)  链路外 3m，即 (1.5, 3.0)
```

| 项 | 要求 |
|---|---|
| 链路长度 | **3.00 m**（实测，不是估计） |
| 天线高度 | 三节点统一 **1.0 m** |
| A / B / C | 自 Tx 沿链路 0.75 / 1.50 / 2.25 m |
| node3 | 链路中点垂直方向 **3.0 m** |
| 地面标记 | 胶带贴十字，重复定位误差 **< 10 cm** |

### 为什么链路必须 ≥ 2 m

三点等分时位置间距 = D/4，而菲涅尔直径 ∝ √D，两者增长速率不同：

| 链路长 | 位置间距 | 菲涅尔直径 | 判定 |
|---|---|---|---|
| 1.0 m | 0.25 m | 0.35 m | **重叠 ✗** |
| 2.0 m | 0.50 m | 0.50 m | 临界 |
| **3.0 m** | **0.75 m** | **0.61 m** | **可分 ✓** |

**另一条独立约束**：位置间距须大于人体躯干宽（0.40–0.50 m），
否则站 A 和站 B 时身体在物理上重合，「三个位置」实为同一位置。

> 8-24 执行时场地原为 1 m 等边三角，核算后重新布置为 3 m。

### 为什么 node3 必须在链路外 3 m

它的作用是**空间对照**：链路外的节点应对 A/B/C 无差别响应。
成立前提是它到三点距离近似相等：

| node3 垂距 | 到 A/B/C | 差异 | 有效性 |
|---|---|---|---|
| 1 m | 1.25 / 1.00 / 1.25 m | 21.4% | ✗ |
| **3 m** | **3.09 / 3.00 / 3.09 m** | **3.0%** | ✓ |

垂距 1 m 时，人站 B 距 node3 仅 1.00 m 会显著扰动它——
**node3 会对 B 响应更强，但这是几何距离差异，不是空间分辨力**。

### 门槛 2：预热

### 门槛 3：干跑

```bash
./csi_lab.sh g_warmup_probe_01 15
```

检查输出：

| 指标 | 要求 | 8-24 实测 |
|---|---|---|
| 匹配率 | > 98% | 99.40% / 99.56% |
| `NON_MONOTONIC` | 0 | 0 |
| `DATA_SUBCARRIERS` | 234 | 234 |

再看 RSSI 是否截顶：

```bash
~/csienv/bin/python - <<'EOF'
import numpy as np, glob
d = sorted(glob.glob('~/csi_results/*g_warmup_probe_01'.replace('~','/Users/YOU')))[-1]
z = np.load(f"{d}/aligned/aligned_csi.npz")
for n in ('node1','node3'):
    r = z[f'{n}_rssi'].astype(float).ravel()
    print(n, np.median(r), 'std', round(r.std(),3))

```

**std 接近 0 说明 RSSI 截顶**（链路太短或增益过高），需调整。

### 门槛 3.5：阳性对照（8-26 新增，最关键）

**在正式采集前，必须验证实验能测出已知量。**

```bash

./csi_lab.sh g_cal_empty_01 20
```

| 指标 | 通过条件 | 8-20 参考 |
|---|---|---|
| **RSSI 下降** | **> 10 dB** | −14.00 dB |
| 频谱变化 | ≥ 17% | 27.27% |

**RSSI 是决定性指标**：频谱变化可能仅来自散射，

> 8-26 实测：四次尝试频谱都有 2–7% 变化，但 RSSI 全部 0.00 dB。
> 若只看频谱会误判为「有微弱响应」而继续采集。

不通过则**该布局不可用**，不要继续。

## 5. 分析与判据

### 5.0 为什么必须有阳性对照

主判据的**类间距离无法先验估计**：
已知人体级散射体造成 17–27% 频谱变化
（金属板 27.27%、真人静站 20.65%、纸箱 17–18%），
但那是「有人 vs 无人」；本实验比较的是**三个都有人**的场景，
共同的「有人」成分会被抵消，**剩下的纯位置差异有多大是未知的**
——这正是实验要回答的问题。

因此无法像 lag 容忍度实验那样事先算出功效，
但可以验证**实验有能力测出已知量**：

| 对照 | 预期 | 不通过的含义 |
|---|---|---|
| 金属板 vs 空场 | 17–30% | 采集或分析链路有问题 |
| 站位 vs 空场 | 17–30% | 同上 |

**判读是两步的**：

| 阳性对照 | 三位置分离度 | 结论 |
|---|---|---|
| 通过 | > 2.5 | 有空间分辨力 |
| 通过 | < 1.5 | **无空间分辨力（可信的阴性）** |
| **不通过** | 任意 | **实验失效，重做** |

没有阳性对照，阴性结果说明不了任何问题。
**这是 8-20 置换检验教训的直接应用：
阴性结论必须先证明实验有功效。**


```bash
python3 scripts/spatial_resolvability.py --date 20260825
```

脚本会依次输出：阳性对照 → 空场稳定性 → 主判据（含零分布 p 值）
→ 空间单调性 → node3 对照 → 留一分类 → 结论。

> 注意：**不要用 `spectrum_shape.py`**。它测的是 trial **内**变化能量
> （条件在 trial 内改变，如人中途走入），
> 而判据实验需要的是 trial **间**类内/类间距离
> （条件在 trial 内不变）。8-20 已记录这两个指标测的不是同一件事。

### 主判据：分离度

```
类内距离 = 同一位置 5 次重复之间的平均 L2
类间距离 = 不同位置之间的平均 L2
分离度  = 类间 / 类内
```

| 分离度 | 判定 | 后续 |
|---|---|---|
| **> 2.5** | 系统**有**空间分辨能力 | H 被推翻 → 路线 A（改协议重采） |
| 1.5 – 2.5 | 边缘 | 每位置扩到 10 次重复再判 |
| **< 1.5** | 系统**无**空间分辨能力 | H 成立 → 路线 B（改物理配置） |

### 辅助判据

1. **空场稳定性** —— 6 条空场之间 L2 < 1%。
   若显著更大，主判据不可信。

2. **node3 对照** —— node3 分离度应显著低于 node1。
   若两者相当，说明测到的是全局变化而非位置。

3. **空间单调性** —— **这是比分离度更强的证据**。
   A/B/C 沿链路排列，若存在空间编码，
   应有 d(A,B) 与 d(B,C) 均小于 d(A,C)。
   随机差异不会呈现空间单调性。

4. **留一分类** —— 3 类 15 样本留一法，随机基线 33%，
   > 60% 支持可分。

### 统计检验

**不使用置换检验。** 8-20 已实测其在 CSI 上失效：
随机置换破坏时间自相关，导致空场数据也 p = 0.0000；
循环块移位对单调漂移同样失效。

**正确做法**：用 6 条空场跑完全相同的分析程序作零分布——
随机分为 3 组算「伪分离度」，重复 200 次。

## 7. 常见问题

**Q: 节点 ping 不通？**
先看 ARP：`arp -an | grep 192.168.50`。
若显示 `(incomplete)`，说明连链路层都没响应，
**只可能是断电或网线问题**，不是 SSH/防火墙问题。
node1 开机慢，需 45 s 以上才能 ping 通。

**Q: RSSI 与几何算的对不上？**
室内多径下**自由空间路径损耗模型不适用**。
8-24 实测：node3 移到链路外 3 m 后，按模型应比 node1 弱 0.97 dB，
实测却强 5 dB。同时 node1 未移动但 |H| 也变了 3.6%——
说明移动一个节点会改变整个多径结构。

**该检查只能用于发现「方向性矛盾」，不能定量测距。**
（8-24 曾据此发现 node3 位置错误：实测强 8 dB
而设计位置应弱 0.97 dB，方向相反 → 查出实际在链路外 1 m。）

**Q: 基线一直不通过怎么办？**
按 `baseline_check.py` 输出的排查顺序：
① 节点是否刚重启/刚移动 → 静置 20–30 分钟；
② trial 内部是否也在漂 → 是则 RF 未收敛或场地有活动；
③ 场地有无人走动、风扇/空调等周期性运动；
④ 有无其他 2.4 GHz 设备干扰。

**Q: 结果落在 1.5–2.5 之间？**
按设计每位置扩到 10 次重复再判。
仍不明确则按「无空间分辨能力」处理——
边缘结果不足以支撑投入大规模重采。

## 8. 这个实验为什么值得

无论结果如何都有价值：

- **通过** → 明确失败原因是协议，可以放心投入正式采集
- **不通过** → 在浪费大量采集时间前止损，且给出明确的配置改进方向

**成本：半天。**
对比：8-11 用一整天采了 15 条 trial，结论全部因设计混杂而作废。

若不通过，按成本排序的改配置方案：

| 改动 | 收益 | 成本 |
|---|---|---|
| 拉大链路夹角至 90° | 改善几何可分性 | 仅移动节点 |
| 带宽 20 → 80 MHz | 距离分辨率 7.5 → 1.9 m | 改 PHY，需重验证 |
| 增加 Rx 节点 | 多链路三角定位 | 需新硬件 |

参考：Person-in-WiFi-3D 原论文用 **3Tx-3Rx 共 9 条链路**、
16 个布局、约 25 万训练帧；我们是 **2 条链路**、1 个布局、约 1500 帧。
论文自己写了 WiFi 定位精度约 0.5 m，而我们实测残差 0.53–1.07 m，
**恰好落在该理论极限上**。详见
[`20260820_paper_config_comparison.md`](20260820_paper_config_comparison.md)。
